# dependencies
- C++ version 15.2.0
- Windows 11
- MSYS2 URCT64 Shell (pacman -S mingw-w64-ucrt-x86_64-toolchain)

# running
Open budget-tracker in MSYS2 URCT64 shell the commands are:
- make (compiles into an executable)
- make run (compiles and runs the executable)
- make clean (removes executable files)
